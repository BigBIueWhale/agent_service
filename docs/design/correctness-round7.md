# Recoverable, qualified continuation

The implementation proceeds in qualified banks: shared captured-stream gate and producer correction together, then bounded compaction retry, constrained snapshots, transactional continuation, and the provider-lifetime, stored-reasoning and operational-metrics migrations. Each bank is an implementation commit followed by its matching release-lock commit; only the qualified pair is pushed.

The first bank's exact boundary is [Shared captured-stream gate and producer contract](shared-stream-gate.md). The versioned emitted-wire schema supplies native and TypeScript structural validators. The production native captured-stream owner is used directly by the service and its gate. Core goal admission is mandatory; JSON adapters validate their complete wire projections. This certificate checks captured facts and their relationships. It does not establish provider settlement, configuration authorization, complete causal provenance, crash-consistent model continuation or semantic fidelity. Those remain actual ownership obligations below. The withdrawn private-authority/WASM expansion is not part of the implementation.

## Compaction, constraints and transactional continuation

A logical compaction freezes the exact pre-transition conversation, pending input, authored instructions, effective generation configuration, referenced workspace versions and acceptance criteria. Pre-compaction hook effects are established once. Each provider attempt has its own identity and independent served-cost/terminal evidence; candidates do not mutate canonical history.

The bounded policy permits at most four total attempts only when a fresh independently sampled completion can plausibly satisfy the unchanged requirement. Malformed model output, missing or unclosed sections, empty snapshot values and unexpected model tool calls belong to that cause class when independent sampling is established. Unsupported schemas, corrupted or unavailable sources, missing checkpoints, invalid fixed configuration, impossible request fit and deterministic repetition require their own named failure. Valid output with uncertain persistence requires commitment reconciliation. None grants resampling.

One versioned schema defines exactly six required nonempty snapshot text fields and no extra fields. That same schema drives actual constrained decoding and host validation; new writers persist one JSON representation. It travels through the ordinary request builder, exact-count/render path and the explicitly supported backend decoder. Reasoning is not constrained before its genuine parser boundary. Unsupported grammar or decoder startup fails explicitly; there is no unconstrained or XML success route. Historical snapshot formats require explicit versioned interpretation or incompatibility.

Before publishing a new history, settle the provider operation, validate the complete candidate, count the actual reconstructed request and persist the accepted transition. Distinguish candidate rejection, durable acceptance and unknown commit outcome. Exhaustion, cancellation, storage failure and unsettled ownership preserve the old state as named recoverable outcomes. Retain immutable resume input and every committed effect, including notes outside the normal workspace. A mutable/container-local path is insufficient. Tool and hook effects with unknown external outcome must reconcile or block by cause; blindly replaying their text is not recovery.

The finite five-share token budget remains the admission policy. It does not prove every authored input or generated summary fits. Exact reconstructed-request checks remain mandatory. Uncapped reasoning means no stricter reasoning-phase cap within the finite request allowance; it does not mean unlimited output capacity.

These compaction, constrained-decoder and continuation integrations remain open. Backend source changes may be committed here if required, but rebuilding and serving the backend belongs to the owner on the second machine. Local stubs cannot qualify that deployed parser/template/decoder combination.

## Provider, stored reasoning and metrics ownership

Provider acquisition, consumption, observation and settlement belong to one mandatory operation scope entered before acquisition. It invokes the actual consuming body, retains its completion and every independent read/close/recording error, including falsy thrown values. Abort precedes joining a blocked read. Fulfilled iterator return with `done:false` is not closure. Diagnostic evidence cannot require the failed consumer to pull more success data to release resources. Timeout settings select waiting policy, never a different ownership implementation.

Every provider, logging wrapper, BaseLlmClient, GeminiChat, Turn, AgentCore, fork and ACP/headless/terminal/SDK consumer must use that same scope. Remove the weaker stream API and provider fallbacks after migration. An uncooperative source enters an explicit unsettled state and transfers to an actual worker/process owner; local reclamation cannot prove remote completion or zero usage. Retry cannot precede required settlement.

One stored-content codec replaces inline reasoning in every canonical carrier. Provider/model content is hydrated where required. Stored records use captured-owner, digest, UTF-8 length and encoding references, with full role, ordering and thought/signature metadata. Persist bytes before admitting a durable reference. Assistant commits, partial failures, adoption, compaction diagnostics/history and child bootstrap/round publication all await that boundary. An artifact failure after generation preserves the attempt and served usage.

Model reconstruction and full export hydrate references; browser/daemon/SDK transcript pages carry reference-aware values and use the owned artifact endpoint. Missing, corrupt, unreadable, invalid-UTF-8 and inaccessible historical references fail by their actual cause. Fork/resume/export preserve reachable objects and ownership mapping; portable bundles include them. The existing 500 MiB owner quota and no-TTL policy are resource choices, not permission to strip thinking or proof of complete graph disposal. New records have one reference representation; identified historical inline schemas remain evidence.

Operational metrics use a process-owned nondestructive snapshot of canonical observations through the actual process/channel RPC. Epoch, source sequence, coverage, outstanding requests, complete observations, eviction and unknown tails remain explicit. The host replaces the same channel's snapshot rather than adding overlapping totals. Failed or reordered acquisition preserves the prior certified snapshot with its actual age and the new failure. Source admission coverage is not dashboard receipt time.

Checked arithmetic and detached public values protect counts. Whole-window percentiles require the complete population or are unavailable; the first 4,096 samples cannot be labeled the whole window. Sensors keep independent successful baselines and real intervals. Missing or stale partner fields do not become zero or freshen old measurements. Viewer-dependent polling means unmeasured intervals, not continuously observed history. Remove metadata drains, token-sniff callbacks, false-zero branches and superseded exactness claims after all consumers migrate. Optional monitoring fails as monitoring; canonical request evidence remains mandatory for execution certification.

All three complete migrations remain open. Local fixes to a ring, generator or compaction event do not close their public obligations.

## Truthful range continuation

The request/tool owner allocates receiving capacity and admits the fully rendered result batch using the ordinary exact-count path. Page selection uses that capacity, framing and other pending results; arbitrary tokenizer prefixes need not be monotone. A validated fitting page is required, not an unsupported claim of a mathematically largest page.

A continuation identifies the exact next position in the same immutable source version, including encoding-safe within-line progress. Explicit requested line count remains a ceiling; a short returned page cannot ratchet later page sizes downward permanently. EOF, changed source, unreadable input and consumed spans are distinct. Remove the hard 25,000-byte output cap and shell-cut escape only when the common range mechanism has truthful full coverage and independently justified I/O/resource bounds. Externalizing an oversized result does not permit a progress-free loop of rereading that same oversized body.

## Artifact gate and qualification limits

The gate must exercise exact final images, real launcher, UID/GID, mounted controls, permissions, capture and exit channels, then feed every event into the production certifier and publish through the service. Preserve nonce/tool, recording and accounting assertions. Include initial idle and nonempty goal transitions, child/side/compaction work, cancelled and malformed output, capture/storage faults and supported historical recovery. New retry/structured/recovery behavior must add its own executable lifecycle cases as those owners are implemented. A synthetic successful Result cannot qualify them.

The schema generator compiles JavaScript validators and TypeScript declarations with pinned dependencies. Its receipt binds source schema, generator, dependency lock and output bytes. The build verifies every generated artifact before compiling and bundling. The native service and launcher carry the same schema identity; startup rejects a mismatched CLI bundle before model work. The SDK copies the complete CLI distribution. Required public declaration bundles, browser size budgets and package test discovery remain qualification obligations.

The broker's production allocation is 128 MiB with no swap after the composition fixture exposed an OOM at 64 MiB. This is an empirically checked resource choice, not a concurrency bound. Cancellation ownership must also join relaunch supervisors, workers, PTYs and capture. Passing a process fixture does not qualify arbitrary platform or remote behavior.

Every relied-on result must identify the exact tested source/artifact and reject a distinguishing fault for the intended cause. Failed or incorrectly constructed qualification fixtures remain evidence of what was not proved. Build inputs, lock manifests and final images must agree before close-out; neither a clean source commit nor a past private image substitutes for a current paired build.

Structural validity, contiguous source delivery and accepted compactions do not prove semantic fidelity. A fixed finite snapshot cannot universally preserve every future-relevant distinction of arbitrary history. Corpus-grounded reference evaluation and task-specific outcomes are still required; no parser, retry rule or second-model approval closes that obligation. No GPU workload, model serving, second-machine contact, release execution or historical-result mutation is authorized in this round.
